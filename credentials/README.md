# Credentials — drop scans here

This folder is the export target for residency and visa packets. Keep **filenames English**, dates ISO (`YYYY-MM-DD`).

| Subfolder | Put here |
|-----------|----------|
| `diploma/` | Degree certificate, diploma supplement, translations |
| `association/` | Artists’ association membership / 美协 letters |
| `exhibitions/` | One PDF or `LIST_EN.md`: year, title, venue, city, solo/group |
| `press/` | Screenshots plus `LINKS_EN.md` with the live URL under each file |
| `papers/` | Essays or catalogues that belong on an **artist** CV |

Do not dump QNM mill JSON, Integrity Audit reports, or `01_Main_Paper` here. If a research paper should appear on the artist CV at all, put a citation and a link to [q-n-s.com](https://www.q-n-s.com/), not the mill source tree.

Large scans may stay local (see `.gitignore` for PSD/TIFF). For applications, export PDF ≤ 5–10 MB each.
