# GitHub Pages

This folder is the public artist site.

## Local preview

Open `docs/index.html` in a browser. No build step.

## Publish (when you create the repo)

1. New **public** GitHub repository. Do not use `qns-website` and do not attach this to `q-n-s.com`.
2. Suggested repo names:
   - User site: `YOURUSER.github.io` (URL becomes `https://YOURUSER.github.io/`)
   - Project site: `studio` under the same user (URL `https://YOURUSER.github.io/studio/`)
3. Put this `docs/` folder in that repo (this whole Studio tree can be the repo; Pages source = `/docs`).
4. Settings → Pages → Branch `main` → folder `/docs`.
5. Later custom domain: copy `CNAME.example` to `CNAME` with the real host.
